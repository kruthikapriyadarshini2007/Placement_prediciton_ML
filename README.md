# 🎓 Placement Prediction System

A Machine Learning project that predicts whether a student will get placed based on academic performance, skills, and experience.  
It also provides a **personalized improvement plan** to help improve placement chances.
---
## 🚀 Project Overview
This project uses multiple Machine Learning models and an ensemble approach to:
- Predict placement status (Placed / Not Placed)
- Calculate placement probability
- Identify weak areas
- Suggest targeted improvements
---
## 🧠 Models Used
- Logistic Regression  
- Decision Tree Classifier  
- Random Forest Classifier  
- ⭐ Ensemble Model (Voting Classifier)
The ensemble model combines predictions from multiple models to improve accuracy and robustness.
---
## 📊 Features Used
- CGPA  
- Projects Completed  
- Internship Experience  
- Communication Skills  
- Aptitude Score  
- Academic Performance (12th)  
- Previous Semester Result  
- Extra Curricular Activities  
---
## 📈 Output
- ✅ Placement Prediction (Placed / Not Placed)  
- 📊 Probability Score  
- 🎯 Skills to Focus  
- 📉 Improvement Plan with expected probability gain
